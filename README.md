This is package version original [Tartarus](https://github.com/aspuru-guzik-group/Tartarus) to run docking easily.

## installation
```
mamba install openbabel rdkit -c conda-forge
pip install git+https://github.com/Xiangyan93/Tartarus.git@package
```
